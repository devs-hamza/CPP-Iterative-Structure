# C++ Iterative Structure

A collection of beginner-friendly C++ console programs that practice **loops, nested loops, conditionals, input validation, calculations, and menu-driven workflows**. The examples include number problems as well as simple billing and management systems.

## 📚 Programs

### Games and Number Problems

1. **[NumberGuessingGame.cpp](NumberGuessingGame.cpp)** — A number-guessing game that gives higher/lower hints and counts attempts.
2. **[ArmstrongNumberSystem.cpp](ArmstrongNumberSystem.cpp)** — Checks whether an entered number is an Armstrong number by processing its digits.
3. **[PrimeNumberSystem.cpp](PrimeNumberSystem.cpp)** — Uses nested `while` loops to find and print prime numbers up to a user-provided limit.
4. **[Prime_Number_Range_Analyzer.cpp](Prime_Number_Range_Analyzer.cpp)** — Finds primes within a start/end range, calculates each prime's digit sum and its parity, and reports the count, total, smallest, and largest prime.

### Billing and Financial Simulations

5. **[ATMManagementSystem.cpp](ATMManagementSystem.cpp)** — A PIN-protected ATM menu for checking balance, depositing money, and withdrawing money.
6. **[ShoppingBillingSystem.cpp](ShoppingBillingSystem.cpp)** — Calculates a shopping bill with quantities, discounts, and tax.
7. **[MenuBillingSystem.cpp](MenuBillingSystem.cpp)** — A menu-driven food ordering and billing program with subtotal, tax, and discount calculations.
8. **[LoanStimulator.cpp](LoanStimulator.cpp)** — Simulates loan repayments using interest rules, payment checks, late fees, and a final summary.

### Booking and Management Systems

9. **[HotelRoomBooking.cpp](HotelRoomBooking.cpp)** — Handles hotel room choices and booking charges, including a long-stay discount.
10. **[GamingTournamentSystem.cpp](GamingTournamentSystem.cpp)** — Processes tournament results and calculates wins, losses, draws, points, ranks, and prize money.
11. **[ParkingLotManager .cpp](ParkingLotManager%20.cpp)** — Tracks car, bike, and bus entry/exit, parking capacity, parking status, and vehicle entries.
12. **[Hospital_Patient_Management.cpp](Hospital_Patient_Management.cpp)** — Provides a menu to register patient details, assess risk from entered readings, calculate room and service charges, and display a patient summary.
13. **[Student_Course_Registration_System.cpp](Student_Course_Registration_System.cpp)** — Simulates course registration with CGPA, semester, and credit-hour eligibility checks, duplicate-registration prevention, course fees, lab fees, and scholarship calculations.

## 🛠️ Compile and Run

You need a C++ compiler such as **g++**.

Compile a program:

```bash
g++ Prime_Number_Range_Analyzer.cpp -o prime_analyzer
```

Run on Linux or macOS:

```bash
./prime_analyzer
```

On Windows, run the generated `prime_analyzer.exe` file. Replace the source filename and output name to compile a different program.

## 🎯 Learning Goals

This repository is a practice collection for building confidence with C++ fundamentals, especially iteration, nested loops, decision-making, calculations, and validating user input.

> These are educational console projects. Test inputs and review each program's logic before relying on its results.
